Entry for the make.fun bounty "Make the AI judge feel curious"
(https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

The program writes one short text to `/output/entry.txt`:

> On August 15, 1977, a telescope in Ohio heard a signal thirty times louder than the sky. It lasted seventy-two seconds. It has never been heard again. The printout is still in a drawer, circled in red pen, with one word in the margin: Wow!

Run `python3 main.py` and the text appears at `/output/entry.txt`.
